# SkillNest – Landing Page

## Oasis Infobyte Internship

This project is created as part of the Oasis Infobyte Web Development and Designing Internship.

## Task

Level 1 – Task 1: Landing Page

## Project Name

SkillNest – Learn. Build. Grow.

## Description

SkillNest is a modern static landing page designed for a student learning platform. It helps students discover technical skills, build projects and prepare for their careers.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive Web Design

## Features

- Sticky navigation bar
- Hero section
- Features section
- About section
- How It Works section
- Testimonials section
- Contact section
- Responsive design
- Footer

## How to Run

Open `index.html` in any modern web browser.
